One sharp, funny loading-screen tip for stressed developers and AI coding agents, in 200 characters or fewer: your agent has read your code three times and still has questions — so do you, and that is why you are both still here at 2 a.m.

## Run it

```sh
node main.ts
```

The program writes the line to the directory named by `MAKEFUN_OUTPUT_DIR` (default `/output`) as `entry.txt`.
